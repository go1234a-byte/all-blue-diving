# 투어 ↔ 다이브 통합 (현재 구현)

## 사용자 흐름
1. 투어 앱에서 투어 예약 → `bookings` 생성 (로그인 사용자만 `diver_id` 연결)
2. 강사는 투어 편집 화면의 "예정 다이빙 계획"에 계획 등록 (`tour_dive_plans`)
3. 다이버는 컴패니언 설정 → 계정 로그인
4. "내 여행"에서 예약 확인, 예정 다이빙과 변경 이력 확인
5. 다이빙 후 기록 올리기 → 날짜 기준 여행 자동 연결 (또는 직접 선택)
6. "올린 기록"에서 계획과 실제 비교

## 변경과 취소
- 투어 날짜·장소·상태가 바뀌면 `tour_change_log`에 자동 기록된다.
- 컴패니언은 새로고침할 때 최신 값을 보여주고, 최근 변경 3건을 표시한다.
- 투어가 취소되면(`cancelled_at` 있음) 여행 카드에 "취소된 여행", 예약이 취소되면 "취소된 예약", 취소 요청 중이면 "취소 요청 중"을 표시한다. 이미 올라간 기록은 자동으로 지우지 않는다.
- 취소된 여행은 업로드 연결 대상에서 빠진다.

## 강사 계획의 성격
- 계획은 참고용이다. 감압 계산 입력이 아니며, 다이브 컴퓨터의 계산 결과가 항상 우선이다.
- 화면에서도 "예정 다이빙 · 강사 계획, 참고용"으로 구분해서 표시한다.

## 아직 없는 것
- 게스트 예약 연결, 여행 일정 캘린더 연동
- 여러 다이브가 같은 날일 때 정확한 1:1 매칭
- 변경 알림 (푸시) — 현재는 열 때 확인
