# 기기 등록 (현재 구현)

## 현재 방식
- "다이브 컴퓨터 기기" = 컴패니언 앱 + 워치 앱 한 쌍. 별도 블루투스 장치는 없다.
- 컴패니언이 설치될 때 UUID를 만들어 `UserDefaults`(`dc.device.id`)에 저장한다.
- 로그인한 상태에서 업로드할 때 `devices` 테이블에 한 번 등록한다 (`name`: "올블루 다이브 컴퓨터", `model`: "Apple Watch").

## 한계
- 기기 식별자는 설치 단위다. 앱을 지우면 새 기기로 등록된다.
- 워치 시리얼 번호는 사용하지 않는다 (앱에서 읽을 수 없음).
- 한 계정의 여러 기기, 기기 교체, 목록 화면은 아직 없다 (P2).

## 다음 단계 (P2)
- 기기 목록 화면, 마지막 동기화 시각 표시
- 기기 이름 변경, 기기 제거 (기존 기록은 남긴다, `device_id`만 null)
