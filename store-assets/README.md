# 스토어 등록 스크린샷 (리디자인 반영)

리디자인된 웹/앱 랜딩(`src/pages/Landing.tsx`)을 스토어 규격으로 캡처한 것.
**실제 업로드(App Store Connect / Google Play Console)는 계정 소유자가 직접 진행.**

## 재생성 방법
```bash
npm run build && npm run preview -- --port 4174    # 별도 터미널
cd store-assets && node capture.mjs                # ios/ , android/ 에 7장씩
```
(로그인 없이 공개 데이터로 렌더. 투어가 있는 달을 자동으로 골라 섹션 2를 채움.)

## 규격
| 플랫폼 | 해상도 | 비고 |
|---|---|---|
| iOS (`ios/`) | 1284 × 2778 | 6.7" (iPhone 14/15 Pro Max). App Store Connect가 요구하는 세트는 수시로 바뀌므로 업로드 전 현재 요구 규격 재확인 필요. 6.9"(1320×2868)도 별도 세트로 요구될 수 있음. |
| Android (`android/`) | 1080 × 2160 | 폰 스크린샷(2~8장, 장변:단변 ≤ 2:1). 1024×500 피처 그래픽은 이번 리디자인과 무관한 추상 그래픽이라 그대로 둠. |

## 업로드 전 확인 필요 (게시 전 콘텐츠 점검)
- **06-instructors**: 강사 카드의 "누적 다이빙 0+" 지표가 실데이터 없음(0)으로 표시됨. 실제 수치가 채워지기 전엔 이 컷은 빼거나, 강사 데이터 보정 후 재캡처 권장.
- **07-reviews / 06-instructors 이미지**: 후기·강사 사진이 아직 예시 스톡(흰동가리·상어 등). 실제 인물/투어 사진으로 교체 후 재캡처하면 더 좋음.
- **02-monthly-tours**: 현재 시드/공개 데이터 기준 10월에 투어가 있어 10월로 캡처됨. 운영 데이터 기준으로 "이번 달"이 비어 있으면 안내 문구만 나오므로, 실제 게시 시점에 투어가 있는 상태인지 확인.

## 스토어 설명 문구
App Store·Google Play 설명 텍스트(현재 동일)는 **구버전 디자인이나 없어진 기능을 언급하는 부분이 없음** — 수정 불필요.
- (선택) 원하면 "■ 주요 기능"에 한 줄 추가 가능: `· 다이빙 여행지·리브어보드 가이드 — 이번 달 어디로 갈지, 코스는 어떻게 되는지 미리 둘러보기`
- `whatsNew`(iOS)는 이번 리디자인 내용으로 이미 갱신함. Google Play "출시 노트"에도 동일 문구 넣으면 됨:
  `홈 화면을 새 디자인으로 전면 개편했습니다. 더 밝고 시원한 톤, 회전하는 대표 이미지, 이번 달 추천 다이빙 여행지와 리브어보드 가이드를 담았습니다.`
