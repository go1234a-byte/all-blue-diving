# 다녀올게 (avatar-trip)

여행 일정을 짜면 내 아바타가 먼저 다녀오는 웹앱 프로토타입. 빌드 과정 없이 정적 파일만으로 돌아갑니다.

## 실행

```bash
cd avatar-trip
python3 -m http.server 8080   # 또는 npx serve .
# http://localhost:8080 접속
```

## 기능

- **일정 짜기**: 오사카·교토 3박 4일 / 도쿄 2박 3일 추천 일정, 또는 다른 도시 직접 짜기
  - 장소 검색(OpenStreetMap Nominatim) 또는 지도에서 직접 찍기
  - 장소마다 머무는 시간, 예상 줄 서기 시간, 입장 시각 지정
  - 이동 시간 자동 계산 (1.5km 이하 도보, 그 이상 전철), 구간마다 구글 길찾기 링크
- **실제 날씨** (Open-Meteo, 키 필요 없음)
  - 출발일이 16일 안이면 실제 일기예보
  - 이미 지난 날짜면 실제 관측 기록
  - 더 먼 미래면 작년 같은 날짜의 실제 날씨를 참고값으로
  - 시간대별 날씨가 장면에 반영 (비 → 우산, 눈, 안개, 낮·밤 하늘, 추우면 목도리)
- **대신 여행 중**: 아바타가 비행기 → 공항 → 이동 → 가게 앞 줄 서기 → 식사·구경·쇼핑 → 숙소 취침을 일정대로 진행
  - 빨리 보기(1초=1분/10분/1시간) 또는 **실제 시간에 맞추기**(현지 시각 기준)
  - 화면을 닫아도 여행이 계속 진행됨 (다시 열면 그만큼 진행돼 있음)
  - 지금 위치를 구글 지도 / 스트리트 뷰로 열기
- **여행 일기**: 들른 곳마다 아바타가 찍은 사진(장면 캡처)과 일기

## 지도

- 기본: **MapLibre + OpenFreeMap** 벡터 지도 (키 필요 없음). 3D 건물, 기울이기·회전, 한국어 지명 우선
- **위성 사진** 버튼: Esri World Imagery 위성 사진으로 전환
- 아바타는 **실제 도보 경로**(FOSSGIS OSRM, routing.openstreetmap.de)를 따라 걷고, 카메라가 내비게이션처럼 따라감
  - 줄 서는 곳에서는 가게 앞에 사람들이 줄을 서 있고, 앞사람이 들어갈 때마다 한 칸씩 앞으로
  - 가게·명소에서는 카메라가 천천히 돌며 주변을 보여 줌
  - 지도를 직접 움직이면 따라가기가 멈추고 '아바타 따라가기' 버튼이 나옴
- 실제 날씨·시간이 지도 위에 겹쳐짐 (비·눈·안개, 해 질 녘, 밤)
- 설정에 **Google Maps JavaScript API 키**를 넣으면 Google 벡터 지도(기울이기·회전, 위성 하이브리드)로 바뀜. 키는 브라우저 localStorage에만 저장

## 파일

| 파일 | 역할 |
| --- | --- |
| `js/data.js` | 추천 일정 데이터 |
| `js/weather.js` | Open-Meteo 예보·과거 기록 불러오기 |
| `js/timeline.js` | 일정 → 분 단위 타임라인 (이동·줄 서기·활동·취침) |
| `js/scene.js` | 아바타 장면 그리기 (Canvas) |
| `js/routes.js` | 실제 도보 경로, 경로 위 위치 계산 |
| `js/map.js` | MapLibre / Google Maps 지도 |
| `js/app.js` | 화면과 상태 |
